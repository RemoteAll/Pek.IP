## 1. 项目速览

- **定位**：国内 + 国外离线 IP 定位库；国内 ip2region xdb v3，国外 MaxMind/DB-IP MMDB，统一结果与合并策略。
- **形态**：库 crate（`pek-ip`），无独立二进制。
- **技术栈**：Rust edition 2024；依赖 `thiserror`、`maxminddb`（feature `mmdb`）、`serde`（可选）、`dhrust`（feature `manager` 时的 HTTP/TLS/插件/zip）。
- **仓库**：`G:\Code\Rust\Pek.IP`（新仓库，远端待配置）。

### 模块总览（`src/`）

| 文件 | 职责 |
|---|---|
| `lib.rs` | 对外入口与模块组织 |
| `xdb.rs` | ip2region xdb v3 读取（IPv4/IPv6，Vector/BTree 索引） |
| `mmdb.rs` | MaxMind MMDB 读取（City/Country/ASN/ISP，自动识别） |
| `region.rs` | ip2region 地域字符串解析（v3，兼容 v2） |
| `locator.rs` | 双源合并、特殊地址短路、统一 `IpLocation` |
| `reserved.rs` | 内网/回环/组播/文档/保留地址分类 |
| `country.rs` | ISO 代码 → 中文名 / 洲名（CLDR 静态表） |
| `manager.rs` | RPanel 组件源按需下载、缓存、启动加载（`load_or_download`） |

## 2. 数据文件

- `data/` 随仓库提供：
  - `ip2region_v4.xdb` / `ip2region_v6.xdb`（Apache-2.0）
  - `dbip-country-lite-2026-10.mmdb` / `dbip-asn-lite-2026-10.mmdb`（CC BY 4.0）
- **不打包**：`Cargo.toml` `exclude = ["data/**", "dist/**", ".ref/**"]`；不要用 `include_bytes!` 嵌入。
- 城市级 MMDB（DB-IP City / GeoLite2 City）体积大，默认不入库；`scripts/fetch-data.ps1 -City` 下载，或用户自行放入。
- **平台地址配置项**：`Config/Ip.toml` 的 `StoreUrl`（默认 `https://p.sc8.fun`；需要换平台只改这一项）。`IpLocator::load_default()` 读取它。
- 业务系统**不配置 `clientId`**：库自动生成 `installId`；信任锚点/配额在 RPanel 管理端配置。
- 更新/上传：`scripts/fetch-data.ps1` → `scripts/pack-ipdb.ps1` → Pek.RPanlServer 组件上传（分类 `ip-database`、目标 `any`）。

## 3. 常用命令

```powershell
cargo check
cargo test
cargo test --all-features       # 含 manager（dhrust HTTP/TLS/插件/zip）
cargo fmt
cargo run --example lookup -- 114.114.114.114 8.8.8.8
cargo run --features manager --example startup -- 114.114.114.114 8.8.8.8
```

## 4. 改动连带影响

- `xdb.rs` 格式解析：必须用真实 `data/ip2region_v4.xdb` 验证（`1.0.1.0`、`114.114.114.114`、`223.5.5.5`）。
- `mmdb.rs` / `locator.rs`：用 `data/dbip-*.mmdb` 或 MaxMind 测试库验证国外结果与合并。
- `manager.rs`：组件源协议与 Pek.RPanlServer `/components/*` 对齐；改动后跑 `cargo test --all-features`（含 Ed25519 + SHA-256 + zip E2E）。
- 平台侧组件包上限已放宽到 128 MiB（`Pek.RPanlServer/src/components.rs`），用于 GeoLite2/DB-IP City。
