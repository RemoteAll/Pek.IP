# 用户档案（Pek.IP 定制部分）

> 通用偏好见用户级《跨项目接续协议》（本机 `%APPDATA%\Code\User\prompts\跨项目接续协议.instructions.md`）；本文件只记录与本项目直接相关的用户口径。

## 已确认口径（含用户原话）

1. 「帮我增加一个Rust的IP库？要能同时支持国内和国外的。而且也最好也是按需支付，我也可以把这个打包上传到RPanel中供按需下载使用」
   - 双源：国内 ip2region + 国外 MMDB；按需从 Pek.RPanlServer 组件源下载。
2. 「仓库要有 `.xdb` / `.mmdb`这些，只是不打包进去，而是给一个教程我将这些文件上传到RPanelServer，启动时如果判断需要就先下载」
   - `data/` 随仓库提供数据文件；crate/二进制不打包；提供 RPanel 上传教程；启动时 `load_or_download` 本地优先、缺失再下载。
3. 「你这个项目也没有像其他的项目一样接入全局用户指令么？」
   - 已装备 `tools/continuity/`、`.vscode/tasks.json`、`.github/copilot-instructions.md`、`docs/项目接续指南.md`、`docs/用户档案.md`、`docs/项目记忆.md`。
4. 「业务系统本身是没有密钥什么之类的对接RpanelServer来下载的，要既能防疲pcdn等刷流量，但又要各业务系统又能正常下载使用，这个是不是要有个什么专门的约定算法。」
   - 待确认并落地“免手工密钥”的下载授权协议（见 `docs/决策记录.md` 的待确认项）。
5. **`Zig.DDNS` 是 Zig 不是 Rust**，不纳入 Rust 工作区（`Pek.Rust.code-workspace` 只挂 `Pek.DDNS/Rust.DDNS`）。
