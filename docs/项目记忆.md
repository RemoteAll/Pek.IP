# pek-ip（Pek.IP）仓库记忆

- 路径：G:\Code\Rust\Pek.IP；crate `pek-ip`，edition 2024；库 crate，无二进制。
- 模块：`xdb`（ip2region xdb v3，IPv4/IPv6、Vector/BTree）、`mmdb`（MaxMind/DB-IP City/Country/ASN/ISP）、`region`（v3 兼容 v2 字符串）、`locator`（双源合并）、`reserved`、`country`（CLDR 中文名）、`manager`（RPanel 组件源按需下载 + `load_or_download`）、`auth`（installId/Ed25519/License/短期票据，零身份自动注册）。
- 数据：`data/` 自带 ip2region_v4/v6.xdb、dbip-country-lite-2026-10.mmdb、dbip-asn-lite-2026-10.mmdb；`Cargo.toml` exclude data/** 不打包。DB-IP City Lite 121MiB 默认不入库（`scripts/fetch-data.ps1 -City`）。
- 打包：`scripts/pack-ipdb.ps1` → `{id}-{version}-any.zip`；平台分类 `ip-database`、target `any`。
- 启动：`IpLocator::load_or_download(IpDbManagerConfig, LocatorLoadOptions)`：本地 data/ → 缓存 → RPanel 下载；默认 allow_partial=true，验签/格式错误不吞。**零配置入口 `IpLocator::load_default()`** 读取 `Config/Ip.toml`（`StoreUrl` 默认 `https://p.sc8.fun`，只改这一项即可换平台；env `PEK_IP_STORE_URL` 优先）。
- 自动授权：`AutoEnroll=true` 首次下载自动生成 `installId`+Ed25519 密钥（StateDir）→ `POST /api/ipdb/enroll` → 平台按 `AutoApproveCidrs` 自动批准或管理员批准 → License → 每次下载 `POST /api/ipdb/ticket` 拿 5 分钟一次性 URL；旧平台 404 自动回退公开下载，403/401 不回退。公开路径 `/api/ipdb/enroll|license|ticket|pubkey`。
- 测试：默认 31 项；--all-features **44 项全绿**、clippy 零警告；真实数据与 RPanel E2E 已过（临时平台，SHA-256/票据/配额/吊销全链路）。
- 平台：Pek.RPanlServer v0.1.43 已实现 `src/ipdb.rs` + `Panl_IpdbClient` 表 + 面板「IP 授权」页；`IpdbTrustAgentNodes` 默认信任已登记服务器节点 IP；`category=ip-database` 包必须带票据，其它组件公开；MAX_PACKAGE_BYTES 128MiB。
